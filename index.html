    Como o projeto foi feito

    Etapas seguidas pela equipe, na ordem.

    1. Levantamento

      Pesquisa dos valores médios de vazão de chuveiro, torneira, vaso sanitário e máquina de lavar.

    2. Protótipo no papel

      Desenho das telas e definição dos campos que o usuário preenche.

    3. Implementação

      HTML para a estrutura, CSS para o visual e JavaScript para o cálculo em tempo real.

    4. Testes

      Validação dos resultados com contas feitas à mão e teste em celular e computador.
